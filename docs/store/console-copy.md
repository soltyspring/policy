# 앱인토스 콘솔 제출 문구 · 동네 정책 찾기

콘솔 입력칸에 그대로 붙여 넣을 수 있게 정리했어요. 해요체, 짧은 문장, 남의 상표·실존 인물 이름 없음.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 앱 이름 | 동네 정책 찾기 |
| appName | `policy` |
| 로고 | `docs/brand/logo-600.png` (600×600 PNG, 각진 정사각형, 흰 배경) |
| 카테고리(추천) | 생활 · 정보 |

> 이름에 "정부24", "보조금24", "토스" 같은 서비스 이름을 쓰지 않았어요. "신청"을 대신해 주는 것처럼 보이지 않게 "찾기"로 했어요.

## 한 줄 소개 (부제)

- **추천:** 우리 동네 정부·지자체 혜택을 한눈에
- 다른 안: 지역별 정부 혜택을 마감 임박순으로
- 다른 안: 사는 지역에서 받을 수 있는 혜택 모아보기

## 앱 설명

```
사는 지역에서 지금 신청할 수 있는 정부·지자체 혜택을 모아 보여 드려요.

· 시·도와 시·군·구를 고르면 그 지역 혜택과 전국 혜택을 함께 보여 드려요
· 마감 임박순, 최근 등록순, 조회 많은순, 이름순으로 정렬할 수 있어요
· 일자리·주거·교육·생활·건강 같은 분야와 청년 대상, 신청 가능 여부로 골라 볼 수 있어요
· 2026년에 바뀐 행정구역(전남광주통합특별시, 인천 제물포구·영종구 등)도 반영했어요

행정안전부 대한민국 공공서비스 정보(공공데이터)를 6시간마다 확인해요.
정부·지자체와 관련 없는 개인 서비스예요. 신청은 각 기관의 공식 페이지에서 해 주세요.
```

## 검수 요청 때 적을 내용

```
공공데이터포털의 행정안전부 대한민국 공공서비스 정보 API로 정부·지자체 혜택을 모아 지역별로 보여 주는 무료 정보 서비스입니다.
로그인·결제·광고가 없고, 사용자 정보는 받지 않습니다(고른 지역은 기기에만 저장).
정책 신청은 하지 않으며, 상세 화면에서 담당 기관의 공식 페이지로 연결합니다.
```
