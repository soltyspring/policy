# 앱인토스 콘솔 입력값 · 동네 정책 찾기

콘솔 "앱 등록하기" 화면 순서대로 붙여 넣으면 돼요.

## 번들 정보

| 칸 | 값 |
|---|---|
| 앱 번들 | `Z:\.solty\dev\appintoss\policy\policy.ait` (`npm run build`로 만든 최신 번들. `ait deploy`로도 이미 올라가 있어요) |
| 출시 노트 | 아래 "출시 노트" 글 |

### 출시 노트

```
정부·지자체 혜택을 지역별로 모아 보여 주는 무료 정보 앱이에요.
1. 첫 화면: "전국에서 신청할 수 있는 정책 N개" 제목의 지역 글자를 누르면 시·도 → 시·군·구를 고를 수 있어요.
2. 목록: 정렬(마감 임박순·최근 등록순·조회 많은순·이름순), 분야 칩, 신청 가능·청년 대상·우리 지역만 조건으로 걸러요. 20개씩 보여 줘요.
3. 상세: 정책을 누르면 지원 내용·대상·신청 방법을 보고 "공식 페이지에서 확인하기"로 담당 기관 페이지를 열어요.
로그인·결제·광고·알림이 없고 사용자 정보를 받지 않아요.
```

### 상세 설명

```
사는 지역에서 지금 신청할 수 있는 정부·지자체 혜택을 한곳에서 볼 수 있어요.

첫 화면 제목의 "전국"을 누르면 시·도 목록이 나오고, 경기를 누르면 경기도의 시·군·구가 바로 이어서 나와요. 지역을 고르면 그 지역 혜택과 전국 혜택을 함께 보여 드려요. 지역을 고르지 않아도 전국 혜택을 바로 볼 수 있어요.

목록 위의 정렬 버튼으로 마감 임박순, 최근 등록순, 조회 많은순, 이름순을 바꿀 수 있어요. 일자리·주거·교육·생활·복지·건강·문화 분야 칩과 "신청 가능", "청년 대상", "우리 지역만"으로 원하는 혜택만 골라 볼 수 있어요. 마감이 가까운 혜택은 D-3처럼 남은 날짜를 보여 드려요.

혜택을 누르면 지원 내용, 지원 대상, 신청 방법을 보고 "공식 페이지에서 확인하기"로 담당 기관 페이지에서 신청할 수 있어요.

2026년에 바뀐 행정구역(전남광주통합특별시, 인천 제물포구·영종구·서해구·검단구 등)도 반영했어요. 정보는 행정안전부 대한민국 공공서비스 정보(공공데이터)를 6시간마다 확인해요. 정부·지자체와 관련 없는 개인 서비스예요.
```
